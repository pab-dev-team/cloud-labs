# Лабораторные работы: книга рецептов

Работы лежат отдельно, каждая папка содержит свою версию приложения и инструкцию:

- [Лабораторная 0](lab0/README.md) — Flask, интерфейс и MySQL.
- [Лабораторная 1](lab1/README.md) — предыдущий сервис за Nginx: HTTPS, два backend, балансировка и отказоустойчивость.

Для каждой лабы есть как и README, так и отчет
Для каждой работы команды запускайте из её папки. Compose-версия первой лабы
использует отдельный Docker volume для MySQL; она не меняет базу, используемую
вручную запущенной версией лабы 0.
